StyleSync Privacy Policy

Last updated: 2026-11-20

1. What we collect

StyleSync does not collect any personal data or usage telemetry. All operations happen locally on your machine.

The only network call occurs when you activate a Pro license key against our verification endpoint (snapmark-license.61960005.workers.dev). This call transmits only the license key string (a short alphanumeric token), which our backend validates and returns a boolean validity result. No other data is sent.

2. What data we store

  • Settings JSON stored in your VS Code user-data directory (%APPDATA%\Code\User on Windows, equivalent paths elsewhere). Only the configuration value stylesync.buyoutLink (empty by default) and stylesync.verifyEndpoint are persisted.
  • Global state managed by VS Code: sv_pro (boolean, true when Pro is activated), sv_license (your Pro license key string, stored locally by VS Code).

We do not create any files outside the standard VS Code user-data path, and we never upload your config files anywhere.

3. Encryption & passwords

Exported ZIP files are encrypted with AES-256-CBC using a key derived from your password via scrypt. Your password is entered in VS Code's secure input dialog and is never transmitted over the network. If you forget your password, there is no recovery — the data is irrecoverable by design.

4. Third-party services

StyleSync uses the following third-party services:

  • Paddle Billing — processes payment for the Pro upgrade. See the Paddle Privacy Policy.
  • Cloudflare Workers — hosts the license verification API at snapmark-license.61960005.workers.dev. Cloudflare's standard logging applies to this endpoint.

There is no third-party analytics, advertising, or tracking within StyleSync.

5. Data retention

Since no user data leaves your machine, there is nothing for us to retain. The license verification log may contain the time of your last verification request; this is not linked to your identity and is used solely for operational monitoring.

6. Contact

For privacy-related questions, email privacy@lxstudio.dev.

7. Changes

We may update this policy. Continued use after changes constitutes acceptance of the new terms.
